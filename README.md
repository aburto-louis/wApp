# wApp

Empty web app

## Stack

| Tool                                                    | Role                                 |
| ------------------------------------------------------- | ------------------------------------ |
| [TypeScript](https://www.typescriptlang.org/)           | End-to-end                           |
| [Bun](https://bun.com/)                                 | Runtime, package manager & toolkit   |
| [Hono](https://hono.dev/)                               | Backend framework                    |
| [Vite](https://vite.dev/)                               | Frontend build tool                  |
| [React](https://react.dev/)                             | UI library                           |
| [TanStack Form](https://tanstack.com/form/latest)       | Headless form state                  |
| [TanStack Router](https://tanstack.com/router/latest)   | File-based routing                   |
| [TanStack Query](https://tanstack.com/query/latest)     | Data fetching & cache                |
| [TanStack Table](https://tanstack.com/table/latest)     | Headless table models                |
| [TanStack Virtual](https://tanstack.com/virtual/latest) | List & grid virtualization           |
| [SQLite](https://sqlite.org/)                           | Embedded db, connect w/ `bun:sqlite` |
| [shadcn/ui](https://ui.shadcn.com/)                     | Accessible component primitives      |
| [TailwindCSS](https://tailwindcss.com/)                 | CSS framework                        |
| [Biome](https://biomejs.dev/)                           | Formatter & linter                   |
| [TurboRepo](https://turborepo.dev/)                     | Monorepo workspace orchestration     |
| [Zod](https://zod.dev/)                                 | Schema validation                    |
